# 导出配置

在服务器详情页点击 **导出配置**，可以下载这台服务器当前使用的 `frpc.toml`，包括通用配置、已启用的代理和访问端。导出的文件可以直接用于原生 frpc，例如迁移回命令行部署、在另一台机器上运行，或者排查问题时查看 Podux 实际生成的配置。

导出时需要注意：

- **代理和访问端名称**：导出的名称是 Podux 在 frps 上实际使用的"名称-ID"，例如 `ssh-abc123def456ghi`。保持不变可以让已经配置好的访问端继续工作；如果改名，其他机器上的访问端也要同步修改。
- **敏感信息**：默认把 token、密钥、插件密码等替换为 `<redacted>`，使用前需要手动填写。勾选 **包含 token、密钥等敏感信息** 后会原样导出，请妥善保存文件。
- **TLS 证书**：Podux 保存的是证书内容，导出文件中改为引用 `certs/cert.pem`、`certs/key.pem`、`certs/ca.pem`，文件开头的注释会列出需要准备哪些文件。请从服务器设置中复制证书内容，保存到对应路径。
- 已禁用的代理和访问端不会导出。

导出的文件也可以再通过 **导入** 页面导入 Podux。
